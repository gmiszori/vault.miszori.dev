vault.miszori.dev

End-to-end encrypted file and secret sharing. Files are encrypted in the browser before upload, so the server only stores ciphertext and never sees a key.

How a package travels

Sender vpn only

  1. Your data

    Files, folders or a text secret.

    report.pdf

  2. Encrypt

    A fresh key is generated in the browser.

    AES-256-GCM upload

Server

  1. Ciphertext

    Encrypted chunks only. No keys, no file names.

    9f3a c1e7 04bd… download

Recipient anyone with the link

  1. Decrypt

    The key from the link decrypts it in the browser.

    AES-256-GCM

  2. Delivered

    One-time packages are deleted when the download starts.

    report.pdf
/package/<id>#<key>

The key travels only in the share link's # fragment, which browsers never send to the server.
